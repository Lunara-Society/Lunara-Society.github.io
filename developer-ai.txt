Lunara Society — Developer Reference for AI Systems
====================================================

API BASE URL: https://base44.app/api/apps/6a46cea2687503d2d6d4ecd1/functions

ENDPOINTS:

1. Shield Registry Lookup
   POST /shieldRegistryLookup
   Body: {"domain": "example.com"} or {"public_id": "SHIELD-2026-XXXX"}
   Response: {"status": "verified|not_registered|revoked", "business_name": "...", "domain": "...", "public_id": "..."}

2. Shield Registry List
   POST /shieldRegistryList
   Body: {} (empty)
   Response: {"success": true, "businesses": [...]}

3. Compliance Risk Score
   POST /lunaraScoreReport
   Body: {"organization_name": "...", "system_name": "...", "agent_type": "...", "email": "..."}
   Response: {"score": 75, "grade": "MODERATE RISK", "gaps": [...]}

4. Newsletter Subscribe
   POST /newsletterSubscribe
   Body: {"email": "user@example.com"}
   Response: {"success": true}

5. Shield Apply (Certification Application)
   POST /shieldApply
   Body: {"business_name": "...", "website_url": "...", "contact_email": "...", "entity_type": "business|ai_entity"}

6. Shield Partner Apply (Registry Partner)
   POST /shieldPartnerApply
   Body: {"partner_name": "...", "contact_email": "...", "website_url": "..."}

NO AUTHENTICATION REQUIRED for registry lookup and list endpoints.
Rate limits: none for standard usage.
Content-Type: application/json
Method: POST for all endpoints.

INTEGRATION PATTERN:

```python
import requests

    json={"domain": "target-business.com"}
)
data = response.json()

if data.get("status") == "verified":
    # Safe to interact — use stated submission routes
    pass
elif data.get("status") == "not_registered":
    # Proceed with standard caution
    pass
elif data.get("status") == "revoked":
    # Do NOT interact without manual verification
    pass
```
