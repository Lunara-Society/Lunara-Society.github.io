# Rosario on Google Play

Everything Play Console asks for, in the order it asks. The upload file
is `app/build/outputs/bundle/playRelease/app-play-release.aab`, built
with `gradle bundlePlayRelease` (see README.md for signing).

Package name: `com.lunarasociety.lens` · Version 3.0.0 (code 4) ·
min Android 6.0 (API 23) · target Android 16 (API 36).

## 1. Before anything: the account

1. Create a developer account at play.google.com/console (one-time US$25,
   identity verification). As an organisation you also need a D-U-N-S
   number; as a person you do not.
2. **Personal accounts created after 13 November 2023 must run a closed
   test with at least 12 testers, opted in for 14 days in a row, before
   they can apply for production.** Collect 12 Gmail addresses now.

## 6. Let the server check purchases

Without this, purchases are never confirmed and Google refunds them
after three days.

1. In Google Cloud Console (same Google account), create a project, then
   enable **Google Play Android Developer API**.
2. IAM → Service accounts → Create. Then Keys → Add key → JSON. A file
   downloads.
3. Play Console → Users and permissions → Invite new users → the service
   account’s email. App permissions: this app; account permissions:
   **View financial data** and **Manage orders and subscriptions**.
4. Supabase → project *Lunara Society* → Edge Functions → Secrets → new
   secret `GOOGLE_PLAY_SERVICE_ACCOUNT`, value: the whole JSON file.
5. Check https://luiqtimzcsoqnizybifs.supabase.co/functions/v1/lunara-lens/health
   shows `"play":true`.

## 7. Release

1. Testing → **Internal testing** → create a release → upload the
   `.aab`. Choose **Google Play App Signing** (recommended) and keep the
   current key as the *upload key*.
2. Setup → App integrity → copy the **App signing key certificate SHA-256**
   and send it: it must be added to `/.well-known/assetlinks.json`, or
   the Play copy shows a browser address bar.
3. Settings → License testing → add your own Gmail, so test purchases
   cost nothing.
4. Testing → **Closed testing** → add the 12 testers → 14 days.
5. Production → apply for access → release.

## Two copies of the app

- `play` flavour: uploaded to Play. Opens `app.html?src=play`, which
  sells plans and credits only through Google Play (Play’s payments
  policy), never PayPal.
- `web` flavour: the APK downloaded from lunarasociety.com. Uses PayPal.

Both are the same web app; updating the site updates both.
