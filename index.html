How verification works

Six steps, and a name against the fourth.

Every one of them is a step you can check afterwards. That is the only reason the process is worth publishing.

  1. 01 Claim

    Something is asserted: about a business, a system, or an obligation in law.

  2. 02 Source

    The primary instrument is attached. The article that sets the date, not a summary of it.

  3. 03 Review

    A named person examines the evidence and signs the decision. There are no anonymous approvals and no automatic ones.

  4. 04 Signature

    The result is signed with Ed25519, so any later edit to the document breaks the signature.

  5. 05 Public record

    It is published where anyone can read it. No account, no key, no rate limit.

  6. 06 Verifiable

    You, or any AI system, can recompute the same answer from the same sources and get the same result.
